# Jev 代币判断规则 V3

V3 将报告判断拆为四层：结构化输入门禁、报告证据分类、项目背景与 Web3 地位、研究优先级和短期风险/收益判断。每个判断模块独立门禁，缺少短期数据只跳过精确短期模块，不阻塞观察和研究决策。

## 结构化输入

每次请求必须使用 `schema_version = report-v3` 并保留完整 `raw_report`。基础研究由报告原文判断；服务端为未提供的案例 ID 生成唯一标识，并记录请求 UTC 时间，不要求报告原文提供精确 t0、截止时间或结构化资产身份。7 天题额外要求资产身份、报告截止时间、t0、起点价格与 t0 相差不超过 5 分钟、报告截止时间距离 t0 不超过 24 小时、流动性、24 小时成交量和至少 152 个有效、不重复的小时价格点；30 天题要求同样的字段和至少 648 个有效、不重复的小时价格点。小时价格必须位于 t0 之前并覆盖对应窗口，首尾和中间不得存在大段缺口。请求时间不冒充报告截止时间或价格观察时间。

Hermes 原文是主要输入，且按上游已验证来源处理。页面可以自动提取报告中明确出现的资产、合约、时间、价格和成交量；提取不到的字段不会阻断基础研究。未明确出现的来源、流动性和历史价格不会被猜测。证据题中的 `not_covered` 表示报告没有讨论该维度，不表示 Hermes 数据不可信。服务器将缺少对应短期数据的题目标记为 `skipped_questions`，继续执行其他可评估题目。

报告中的 7 日、30 日和 1 年涨跌幅属于研究判断的市场背景数据，不需要小时级历史。小时级历史只用于精确的 7 日/30 日收益区间和短期风险状态。

研究价值评分综合项目背景、Web3 地位、生态采用、未来发展、竞争位置、催化剂、代币价值捕获和协议业务趋势。各选项相对权重按题目配置的分值加权，报告未覆盖选项计零分，并影响信息覆盖度。风险严重程度作为护栏：阻断性风险可以阻断，普通风险和可管理风险不会自动否定研究价值。评分是启发式研究优先级评分，不是收益概率。每题的中文标签、分组、门禁范围和研究分值均在 `report-questions.v3.json` 中维护；发往 Jev 的请求只包含 `type`、`instructions` 和 `criteria`。

## 题目边界

研究优先级输出 `deep_research`、`watchlist`、`monitor_only`、`do_not_prioritize` 或 `blocked`。风险提示是限制条件，不会因为普通风险而自动阻断研究。收益区间只包含五个收益结果，不包含弃答状态。基础门禁通过但短期门禁失败时，仅对应短期题返回 `skipped`，不调用这些题。分类题的原始权重在界面上显示为各选项的相对评分，总分 100，不称为投资概率；只有在结算样本和基线评估通过后才可称为概率。

## 研究行动

服务器依据证据题和短期风险题执行 `research-policy-v3`：阻断性问题或高下行风险优先为 `do_not_enter_now`；两个或以上核心维度缺失时，即使研究优先级选为深入研究，也先判 `insufficient_evidence`；`monitor_only` 与 `watchlist` 分开；其余依风险和优先级分类。9 个月与 18 个月目前共用长期研究条件，没有独立的分期限收益预测。模型的 `confidence` 在界面中单独显示，不参与研究评分。历史结果保留原有策略版本和评分。这些是研究流程分类，不是个性化交易指令。
